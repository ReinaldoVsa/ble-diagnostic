Sobre o aplicativo

BLE Diagnostic Scanner — versão 1.2.1

Ferramenta de diagnóstico e inventário para dispositivos BLE autorizados. Não executa operações financeiras nem comandos operacionais de caixa eletrônico.

Compatibilidade

Recursos BLE suportados por este navegador

Diagnóstico de compatibilidade

Recursos indisponíveis não são simulados: as funções correspondentes informam quando dependem de suporte do navegador.

Wi-Fi: navegadores não oferecem API para detectar ou conectar redes — a conexão automática está prevista apenas para a versão nativa Android (ver README).

Permissões

Por que o aplicativo precisa de cada permissão

Bluetooth

Necessário para procurar e conectar a dispositivos BLE. O acesso é concedido pelo navegador a cada busca, e apenas ao dispositivo que você selecionar.

Localização (quando exigida pelo sistema)

Em alguns sistemas (especialmente Android), o sistema operacional exige permissão de localização para varredura Bluetooth, pois anúncios BLE podem indiretamente revelar posição. O aplicativo não usa nem armazena sua localização.

Permissão de conexão

Cada conexão GATT é solicitada explicitamente ao navegador. O aplicativo nunca tenta contornar permissões do sistema.

Privacidade

Como seus dados são tratados

  • Os dados ficam localmente no seu dispositivo, por padrão (IndexedDB).
  • Nenhum dado é enviado para servidor sem implementação explícita e consentimento.
  • O aplicativo não coleta dados bancários.
  • O aplicativo não armazena senhas.
  • O aplicativo não executa operações financeiras.
